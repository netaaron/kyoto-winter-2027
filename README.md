# 京都冬旅 2027：京都三天兩夜旅行網站（第四版，照片版）

2027/1/28（四）– 1/30（六），兩位大學同學的京都冬季旅行。
以 16 張 AI 生成的寫實照片為主視覺，版面參考日本旅遊雜誌；出發前是旅行手帳，出發後切換成旅途模式。
照片是情境示意，不是實地拍攝，網站頁尾有標註。

## 網站內容

- **封面**：雪中八坂塔照片，深色模式自動換成夜景，雪花動畫，「開始探索旅程」「查看完整行程」
- **旅行概要**：日期、航線、旅伴、住宿、預算，加上出發倒數
- **三日行程**：第一到第三日分頁，每個時段可展開細節（介紹、停留時間、交通、費用、拍照建議、Google 地圖與導航），可打勾，有進度條
- **京都路線地圖**：四張手繪風格路線圖（全部路線、第一日到第三日），點按鈕切換、點圖放大；右側列表點地點看介紹與導航
- **景點**：七個主要景點，各配一張照片
- **在京都吃什麼**：錦市場小吃、京都拉麵、抹茶與和菓子
- **住宿**：京都十字飯店，已查證的入住時間、車站距離、住宿稅
- **預算與記帳**：可調整每人預算、新增或移除項目；旅途記帳支援日圓與台幣、記錄誰付錢，自動算出「誰應給誰多少」，可複製結算貼到 LINE
- **兩支手機合併記帳**：按「把記帳傳給旅伴」產生連結，對方打開後確認，就會把沒有的記錄合併進去（只新增、不刪除）
- **交通**：九段交通，每段都有導航連結
- **旅行攻略**：手機 ICOCA、冬季穿搭、2026年11月起的退稅新制、住宿稅、市巴士、緊急電話，附資料來源
- **冬日京都**：14 張照片，可放大瀏覽、左右滑動切換
- **行前清單**：出發前、行李、手機準備三組，共 24 項
- **旅途模式**（網址加 `#travel`）：下一站、一鍵導航、完成打卡、快速記帳與結算、給店員看的日文小卡（12 句，含計程車回飯店）、京都天氣預報連結、飯店日文地址一鍵複製
- **離線與主畫面**：打開一次後會存到手機，沒有網路也能看已經看過的內容；可用 Safari「加入主畫面」，像 App 一樣打開
- **分享預覽**：傳到 LINE 時會顯示封面照片與標題

## 資料標記

每項事實都標記狀態：**已查證**（2026年11月查核）、**估算**、**出發前確認**。
所有行程資料集中在 `assets/js/data.js`，改日期、預算或飯店，整個網站會一起更新。
打勾、記帳、清單只存在使用者自己手機的瀏覽器裡。

## 檔案

```
index.html
assets/css/style.css
assets/js/data.js        全部行程資料（唯一資料來源）
assets/js/app.js         互動功能
assets/fonts/            昭源宋體、Newsreader、馬善政（只含用到的字）
assets/photos/           16 張照片與 4 張路線圖，各有大小兩種尺寸（WebP）
assets/icons/            主畫面圖示
assets/og.jpg            LINE 等分享預覽圖
manifest.webmanifest     加到主畫面的設定
sw.js                    離線快取（版本號在每次建置時自動更新）
making-of/               製作紀錄頁
```

## 部署到 GitHub Pages

把整個資料夾放到 repo 根目錄，在 Settings → Pages 選 main 分支。不需要建置步驟。
